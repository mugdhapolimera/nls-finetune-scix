Step-by-Step Walkthrough

Example: "PhD theses about galaxy evolution from CfA"

1
Heuristics Pipeline rules-based, <20ms

Pattern matching extracts authors, years, institutions, bibstems, objects, and topics. Validated against curated synonym lists.

Output: IntentSpec (Heuristics)
{ "free_text_terms": ["galaxy evolution"], "affiliations": ["CfA"], "bibgroup": ["CfA"] }

Heuristics catch affiliations and bibgroups but can't understand "PhD theses" = doctype:phdthesis.

2
RAG Retrieval parallel with heuristics, <20ms

BM25 finds 2-3 similar gold examples from 4,924 training pairs. Injected as few-shot user/assistant pairs before the user query. Field cards with valid enum values also injected.

Retrieved few-shot examples
1. "PhD theses on galaxy evolution" -> {"free_text_terms": ["galaxy evolution"], "doctype": ["phdthesis"]} 2. "looking for masters theses" -> {"doctype": ["mastersthesis"]}
3
Fine-Tuned LLM Qwen3-1.7B, ~500ms

Generates <think> reasoning followed by IntentSpec JSON. Understands operators, negation, metrics, doctypes.

LLM output
<think> User wants PhD theses about galaxy evolution. Doctype: phdthesis. </think> {"free_text_terms": ["galaxy evolution"], "doctype": ["phdthesis"]}
4
Intent Merge <1ms

Per-field policies combine the best of both intents. Each field has a preferred source.

Merged result
{ "free_text_terms": ["galaxy evolution"], // LLM (preferred) "affiliations": ["CfA"], // Heuristics (validated) "bibgroup": ["CfA"], // Heuristics "doctype": ["phdthesis"] } // LLM (Heuristics can't detect)
5
Assembler deterministic

IntentSpec -> valid ADS query. Always produces correct syntax.

Assembled query
abs:"galaxy evolution" (inst:"CfA" OR aff:"CfA") bibgroup:CfA doctype:phdthesis
6
Runtime Augmentation post-assembly

Five modules transparently enhance the query at serving time. No retraining needed.

Final query
(abs:"galaxy evolution" OR uat:"Galaxy evolution") (inst:"CfA" OR aff:"CfA") bibgroup:CfA doctype:phdthesis

Merge Policies

FieldSourceWhy
authorsHeuristicsBetter name formatting ("Last, F" format)
free_text_termsLLMUnderstands context, distills verbose descriptions
year_from/year_toHeuristicsValidated against date patterns
affiliationsHeuristicsValidated against institution_synonyms.json
bibstemsHeuristicsValidated against bibstem_synonyms.json
operatorLLMHandles citations(), trending(), similar()
negationLLM onlyHeuristics can't detect "excluding", "without"
citation_countLLM onlyHeuristics can't extract numeric thresholds
doctype / propertyUnionBoth contribute; strips doctype:article for generic "papers"

Runtime Augmentation (5 Modules)

UAT (Unified Astronomy Thesaurus) — 4,144 terms

abs:"dark matter"-->(abs:"dark matter" OR uat:"Dark matter")
abs:"exoplanet atmospheres"-->(abs:"exoplanet atmospheres" OR uat:"Exoplanet atmospheres")

Planetary Feature Gazetteer — 8,915 terms

abs:"Olympus Mons"-->(abs:"Olympus Mons" OR planetary_feature:"Olympus Mons")

Institution Expansion — 56 institutions, 170 synonyms

aff:"NASA"-->(inst:"JPL" OR inst:"GSFC" OR inst:"NASA Ames" OR inst:"MSFC" OR aff:"NASA")
aff:"Max Planck"-->(inst:"MPA" OR inst:"MPE" OR inst:"MPIA" OR aff:"Max Planck")

Bibstem Normalization — 70 journal mappings

bibstem:"Nature"-->bibstem:"Natur"
bibstem:"Astrophysical Journal"-->bibstem:"ApJ"

Complex Author Wildcarding

author:"El-Badry"-->author:"El*Badry*"
author:"de Groot-Hedlin"-->author:"de*Groot*Hedlin*"
